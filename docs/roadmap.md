# Development Roadmap

## Phase 1: Foundation (Weeks 1-2)

- Plasmo MV3 baseline and minimal permission model.
- Gmail and Outlook artifact extraction.
- Rule engine v1 and risk scoring v1.
- Local IndexedDB schema and policy framework.

## Phase 2: Local AI and Threat Intel (Weeks 3-5)

- Quantized NLP model integration and fallback heuristics.
- ONNX runtime tuning and cache strategy.
- Threat feed ingestion, hashing, Bloom lookup.
- Explainable indicator ranking pipeline.

## Phase 3: UX and Enterprise Hardening (Weeks 6-8)

- Premium SOC-style UI and risk visualization.
- Inline banners and side panel experiences.
- Managed policy controls and admin mode.
- Security review and threat-model driven hardening.

## Phase 4: Validation and Rollout (Weeks 9-10)

- Red-team phishing simulation corpus validation.
- Performance and memory benchmarking on enterprise endpoints.
- Pilot deployment through Intune and Google Workspace.
- Ring-based rollout and rollback readiness.

## Phase 5: Advanced Detection (Post-GA)

- QR phishing detection from embedded images.
- Fake login page visual heuristics.
- Behavioral clustering for campaign-level local correlation.
- Optional federated signal sharing architecture (privacy-preserving, opt-in).
